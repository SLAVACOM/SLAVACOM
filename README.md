### 👋 Привет! Меня зовут Святослав

Я Java backend-разработчик, специализирующийся на создании масштабируемых и отказоустойчивых систем.

💼 **Основной стек**:  
Java 17+ · Spring Boot · Docker · PostgreSQL · Kafka · NestJS + NextJS для бытрого создания fullstack   

🔧 Разрабатываю надёжные backend-сервисы, REST API и микросервисы.  
🔁 Активно применяю CI/CD, контейнеризацию и автоматизацию.  
🧠 Увлекаюсь проектированием архитектуры и DevOps-практиками.
